# RAF Work Rate Test Simulator

A browser-based simulation of the RAF Work Rate (Code Checking) test used 
in RAF aptitude assessments.

## What it does
- Generates 20 randomized questions from a shuffled grid of letters, 
  numbers, and symbols
- 4-minute timer (matching the real test conditions)
- Auto-advances on answer selection
- Scores accuracy and completion

## How to use
Open `index.html` in any modern browser, or visit the live demo:

**[Live Demo](https://yourusername.github.io/raf-work-rate-test/)**

## How the test works
You're given a code (e.g. `RDS`). You must find the option (A–E) that 
uses the *other items* from the *same columns* in the *same order*.
